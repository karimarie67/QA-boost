## 🚀 Getting Started

### Trigger Your First Test Run:

1. Go to the [Actions tab](../../actions)
2. Select "QA Test Suite - Boost.org"
3. Click "Run workflow"
4. Choose environment (staging/production)
5. Watch this dashboard update automatically!
